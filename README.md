APIScout Studio 🚀
[TR] APIScout Studio, OpenAI, Google Gemini, OpenRouter ve Groq API anahtarlarınızı doğrulayan, kullanılabilir modelleri listeleyen ve sekmeli Playground arayüzüyle modelleri anında test etmenizi sağlayan masaüstü uygulamasıdır. %100 lokal çalışır, API anahtarınız tamamen güvendedir.

[EN] APIScout Studio is a desktop application to validate API keys for OpenAI, Google Gemini, OpenRouter, and Groq, list available models, and test them instantly via a tabbed Playground UI. It works 100% locally to keep your API keys safe.

🌟 Features / Özellikler
🔑 Multi-Provider Support / Çoklu Sağlayıcı: OpenAI, Google Gemini, OpenRouter, Groq

🔍 Model Scanner / Model Tarama: Instantly fetch accessible models / Erişilebilir tüm modelleri saniyeler içinde listeleme

💬 Interactive Playground / Dahili Playground: Test models in tabbed chat interfaces / Sekmeli sohbet ekranıyla modelleri test etme

🌍 Multi-Language / Çoklu Dil: English, Türkçe, Español, Français

🔒 100% Client-Side / Tamamen Lokal: No server-side logging; keys are processed locally / API anahtarları yalnızca yerelde işlenir

🛠️ Quick Start / Hızlı Başlangıç
Run from Source / Kaynak Koddan Çalıştırma
git clone https://github.com/USERNAME/APIScout.git

cd APIScout

pip install requests

python APIScout.py

Build Executable / .exe Derleme
pip install pyinstaller

pyinstaller --noconsole --onefile APIScout.py
