APIScout Studio 🚀

[TR] APIScout Studio, OpenAI, Google Gemini, OpenRouter ve Groq API anahtarlarınızı doğrulayan, kullanılabilir modelleri listeleyen ve sekmeli bir Oyun Alanı arayüzü kullanarak bunları anında test etmenizi sağlayan bir masaüstü uygulamasıdır. Tamamen yerel olarak çalışır ve API anahtarlarınızın güvenliğini sağlar.

[EN] APIScout Studio is a desktop application to validate API keys for OpenAI, Google Gemini, OpenRouter, and Groq, list available models, and test them instantly via a tabbed Playground UI. It works 100% locally to keep your API keys safe.

🌟 Features
🔑 Multi-Provider Support: OpenAI, Google Gemini, OpenRouter, Groq

🔍 Model Scanner: Instantly fetch accessible models

💬 Interactive Playground: Test models in tabbed chat interfaces

🌍 Multi-Language: English, Turkish, Spanish, French

🔒 100% Client-Side: No server-side logging; API keys are processed locally.

🛠️ Quick Start
Run from Source
git clone https://github.com/USERNAME/APIScout.git

cd APIScout

pip install requests

python APIScout.py
Build Executable
pip install pyinstaller

pyinstaller --noconsole --onefile APIScout.py
